# Experiment 04 – OpenCV Client

## Objective

Receive the ESP32 camera stream on the MacBook and process it using OpenCV.

This is the first experiment where the MacBook begins acting as the robot's "brain."

---

## Learning Objectives

- Receive network video streams
- Learn OpenCV basics
- Display live camera frames
- Prepare for computer vision algorithms

---
