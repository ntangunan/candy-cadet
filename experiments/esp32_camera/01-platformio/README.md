# Experiment 01 – PlatformIO Development Environment

## Objective

Establish a reliable embedded development environment for the ESP32 using VS Code and PlatformIO.

This experiment verifies that the entire development toolchain works before introducing additional hardware or software complexity.

---

## Learning Objectives

- Learn the PlatformIO project structure
- Build and upload firmware
- Use the serial monitor for debugging
- Understand the firmware development workflow
- Become comfortable with Git-based embedded development

---

## Hardware

- Freenove ESP32-WROVER Camera Board
- USB cable
- MacBook Pro (2016/2017)

---

## Software

- VS Code
- PlatformIO
- Arduino Framework
- Git

---

## Tasks

- [X] Create PlatformIO project
- [X] Build firmware
- [X] Upload firmware
- [X] Print "Hello World" over Serial
- [X] Verify serial monitor output

---

## Success Criteria

The ESP32 repeatedly prints status messages over the serial monitor without errors.

Example:

```
Claptrap Experiment 01

ESP32 Running
ESP32 Running
ESP32 Running
```

## Concepts Learned

- Firmware compilation
- Flashing embedded devices
- Serial communication
- Embedded debugging
- PlatformIO workflow
