# Experiment 03 – Camera Web Server

## Objective

Stream images from the ESP32 camera over Wi-Fi.

This experiment transforms the ESP32 into a small web server capable of serving camera images to another computer.

---

## Learning Objectives

- Learn ESP32 Wi-Fi programming
- Understand HTTP servers
- Stream images over a network
- Measure latency
- Understand networking fundamentals

---

## Hardware

- Freenove ESP32-WROVER
- Wi-Fi Network
- MacBook

---

## Tasks

- [ ] Connect to Wi-Fi
- [ ] Display IP address
- [ ] Start HTTP server
- [ ] Capture images
- [ ] Serve JPEG image
- [ ] Stream MJPEG video

---

## Success Criteria

Opening the ESP32 IP address in a browser displays a live camera stream.

Example:

```
http://192.168.1.xxx
```

---

## Concepts Learned

- HTTP
- Wi-Fi
- TCP/IP
- Image streaming
- Network debugging
